## 当前版本：第一章v0.2-增加cg与配乐

在第一章 v0.1 的基础上，本版完善开场、结尾、音乐和视觉反馈。

- **绘本开场**：书放在手绘木质书桌上，英文艺术字封面为 TIN HEART。封面绕书脊缓缓打开，展开后在新书页上依次浮现章节标题和旁白。修复翻动过程中重复显示完整展开书本的问题，替换旧标题页。
- **取锡兵演出**：书页文字之后，保留小孩从盒子里逐个取出、摆放锡兵的动画。取出独腿锡兵时，镜头放大并跟随手；落桌晃动后站稳，再恢复正常镜头并进入教程。
- **窗台结尾**：最后相遇时强制站立并推近镜头，至少欣赏舞女 10 秒后解除锁定。玩家重新按下移动、跳跃或立正时，大手出现，将锡兵拿起放到窗台；镜头连续跟随，放稳后手退出。窗台是本章演出终点，第二章尚未接入。
- **原创配乐与音效**：绘本使用独立柔和前奏，取锡兵与探索使用钢琴曲，舞女使用八音盒舞曲；循环接头加入两小节尾音重叠，曲目切换采用约 4.5 秒交叉淡化。成功收集纸星时播放短促双音铃声。音乐、音效均由项目工具合成，未使用外部采样。
- **字体与文案**：采用何某手写体及霞鹜文楷缺字后备，保留字库来源和 SIL OFL 许可；文字统一黑色填充、白色描边。第 13 关改为低矮通道提示，第 30 关改为“相遇”，删除风向文字提示。
- **风力与画面**：风在空中持续影响水平速度，方向键仍可调整；立正仅在地面抗风。修复左向风效反转和教学出口书堆被桌沿遮挡。纸星稍微放大，并加入光晕、缓慢明暗变化与轻微浮动，仍只由锡兵下半身接触收集。

新增绘本、书桌、手部、窗台美术均由内置 image_gen 生成，素材与提示词保存在 `assets/cinematics/`；配乐及收集音效在 `assets/audio/`，制作工具在 `tools/`。开场、结尾、音乐切换、空中风力和收集逻辑均经过自动检查，演出画面也经过实机截图检查；完整关卡难度与游玩时长仍需真人试玩。

F5 运行第一章。Enter 跳过开场，C 继续保存的旅程，K 跳过当前关卡，R 重试，Esc 暂停。操作与章节详情见 [CHAPTER01.md](CHAPTER01.md)。

## 锡兵五动作示范

F5 运行第一章开场 CG、教学、30 房间长关卡，最后抵达纸城堡。长关卡初玩目标约 20 分钟，待真人试玩校准。开场按 C 可继续已保存的房间。详见 CHAPTER01.md 与 design/TABLETOP_JOURNEY.md。原动作测试仍可按 F6 运行 `scenes/action_demo.tscn`。

- A D / 左右箭头：走路。
- Shift / S / 下箭头：按住立正，站稳抵抗风和坡面滑动，不能移动。
- 空格：短按松开小跳；长按约 0.35 秒准备完成后松开固定幅度大跳。
- R / 1：回到平地；2：前往风坡。它们是示范场景的测试快捷键，不是角色能力。

锡兵使用独立蜡笔剪纸 PNG 部件组成的独腿纸偶，带可见关节钉。大跳有压低身体的准备动作，落地有缓冲和回正。落地控制锁定 0.06 秒，恢复动画共 0.26 秒，参数均可在 `scripts/tin_soldier.gd` 修改。小跳在松开按键时起跳；进入蓄力后未满 0.35 秒松开也执行小跳。短按判定阶段保留走路，超过 0.12 秒才停止水平移动进入蓄力。

增强版移动速度为 260 像素每秒，小跳起跳速度为 520、大跳为 760，重力为 1500。无风同高度时，理论小跳高度约 90 像素、距离约 180 像素；大跳高度约 193 像素、距离约 263 像素。实际碰撞与离散步进会略有差异。

本次示范暂采用立正期间可稳定蓄力、起跳解除稳定的规则，尚未作为最终设计确认。无攻击、冲刺、二段跳或攀墙。美术已替换为生图制作的手绘剪纸素材，色块版本保留在 scripts/soldier_block_art.gd。

走路表现为单腿连续小蹦：约每 0.26 秒一次，先落脚压低身体，再整个人偶连同鞋子抬升约 18 像素，回落后重复。去掉走路时左右摆身和摆腿，保留轻微固定前倾与手臂平衡动作。这是视觉步态，碰撞体仍平顺移动，不会自动越过障碍或触发小跳能力。走路节拍和高度可在 `scripts/soldier_art.gd` 调整。
