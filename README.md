## 锡兵五动作示范

在 Godot 中按 F6 运行 `scenes/action_demo.tscn`，或按 F5 运行项目。

- A D / 左右箭头：走路。
- Shift / S / 下箭头：按住立正，站稳抵抗风和坡面滑动，不能移动。
- 空格：短按松开小跳；长按约 0.35 秒准备完成后松开固定幅度大跳。
- R / 1：回到平地；2：前往风坡。它们是示范场景的测试快捷键，不是角色能力。

锡兵使用独立蜡笔剪纸 PNG 部件组成的独腿纸偶，带可见关节钉。大跳有压低身体的准备动作，落地有缓冲和回正。落地控制锁定 0.06 秒，恢复动画共 0.26 秒，参数均可在 `scripts/tin_soldier.gd` 修改。小跳在松开按键时起跳；进入蓄力后未满 0.35 秒松开也执行小跳。短按判定阶段保留走路，超过 0.12 秒才停止水平移动进入蓄力。

增强版移动速度为 260 像素每秒，小跳起跳速度为 520、大跳为 760，重力为 1500。无风同高度时，理论小跳高度约 90 像素、距离约 180 像素；大跳高度约 193 像素、距离约 263 像素。实际碰撞与离散步进会略有差异。

本次示范暂采用立正期间可稳定蓄力、起跳解除稳定的规则，尚未作为最终设计确认。无攻击、冲刺、二段跳或攀墙。美术已替换为生图制作的手绘剪纸素材，色块版本保留在 scripts/soldier_block_art.gd。

走路表现为单腿连续小蹦：约每 0.26 秒一次，先落脚压低身体，再整个人偶连同鞋子抬升约 18 像素，回落后重复。去掉走路时左右摆身和摆腿，保留轻微固定前倾与手臂平衡动作。这是视觉步态，碰撞体仍平顺移动，不会自动越过障碍或触发小跳能力。走路节拍和高度可在 `scripts/soldier_art.gd` 调整。
