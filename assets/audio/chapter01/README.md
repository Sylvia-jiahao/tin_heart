# 第一章原创配乐

两首配乐在本项目内原创编排并合成，没有使用外部歌曲、录音或采样包。

| 文件 | 用途 | 节奏 | 时长 |
| --- | --- | --- | --- |
| paper_castle_walk.wav | 开场、教学和第一章探索；柔和合成钢琴 | 72 BPM，4/4 | 文件 113.33 秒，循环周期 106.67 秒 |
| paper_dancer_waltz.wav | 遇见纸舞女后；八音盒 | 100 BPM，3/4 | 文件 61.2 秒，循环周期 57.6 秒 |

探索曲改用柔和合成钢琴，主旋律、低音及伴奏均使用钢琴音色；舞女舞曲均使用八音盒。舞曲每小节 1.8 秒，对应舞女原有旋转周期。

每个文件在原曲末尾增加两小节衔接：旧乐句的自然尾音与下一轮开头做平滑的等功率重叠；播放器循环回到开头衔接之后的位置，所以完整循环仍保留原有 32 小节与节拍。探索曲衔接长 6.67 秒，舞曲长 3.6 秒。音频没有外部采样，钢琴为本项目合成音色，并非录音钢琴。

两首曲子之间改为 4.5 秒的等功率交叉淡化，起止使用平滑曲线，避免线性淡化中间音量凹陷及尾音突然截断。换关和重试不会重新开始乐曲；暂停期间音乐随游戏暂停。重播第一章会重新开始探索配乐。

可在《锡心》及其课程展示、发行包、宣传视频中使用、修改和重新编排。本记录说明本项目的制作来源，不声称存在第三方授权证书或平台对生成内容授予独占版权。

可修改音符与编排源：tools/compose_chapter01.py。音符、节奏与音频分析记录：score.json。播放与音量入口：scripts/chapter_music.gd。

验证：tools/check_chapter_audio.py 检查实际循环点处的 PCM 连续性、峰值和节拍周期；tests/music_loop_check.gd 验证引擎真实播放至结尾后进入正确循环位置；tests/chapter_audio_font_check.gd 检查换曲中间音量、渐变完成、暂停与恢复。
